// Engineer robot squads (tf_robot_squad_enabled 1)
//
// Every Engineer teleporter exit is also a robot factory for its team. Like an MvM
// engineer's teleporter, it sends robots through one at a time until the squad is
// full, and refills each robot's place a while after it dies. Higher teleporter
// levels send robots faster, and squads can add members (or giants) per level.
//
// Engineers pick their squad from the Robot Factory menu: right-click with the build
// PDA out, or bind "tf_robot_squad_select" (or "tf_robot_squad_select <Name>").
// Each Squad below is one entry in that menu. Until they pick, they get "default".
//
// Per-map squads: scripts/robot_squads/<mapname>.txt uses this same format. Its
// templates and squads are added to these, and a squad with the same Name as one
// here replaces it on that map (e.g. a version without a giant for tight maps).
// Put "ReplaceGlobalSquads" "1" at the top of a map file to use only its squads.
//
// Squad keys:
//   Name           id for the squad ("default" is what Engineers start with)
//   DisplayName    what the menu shows (keep it under ~30 characters)
//   SpawnInterval  seconds the exit takes to send each robot through, otherwise
//                  tf_robot_squad_spawn_interval (giants use tf_robot_squad_giant_spawn_time)
//   RespawnDelay   seconds after a robot dies before its place is refilled,
//                  otherwise tf_robot_squad_respawn_time
//   TFBot { }      a squad member
//
// TFBot keys are the same as in MvM popfiles (Class, Name, Health, Scale, Skill,
// WeaponRestrictions, Attributes, Item, ItemAttributes, CharacterAttributes, Tag,
// MaxVisionRange, Template) plus:
//   Count          how many of this member (default 1)
//   MinLevel       lowest teleporter level this member shows up at (default 1)
//   MaxLevel       highest teleporter level this member shows up at (default 3)
//   SpawnTime      seconds the exit takes to send this member through
//   Model          a custom robot model (UseCustomModel works too), e.g.
//                  "models/bots/soldier/bot_soldier_gray.mdl" - the files go in
//                  mod_tf/custom/. Loadouts can set their own Model as well.
//   UndeadModel    model during Halloween / Full Moon instead of the zombie look
//                  (Snipers default to the skeleton Sniper if it's installed)
//   Loadout { }    a loadout this member can carry (see below) - list several
//
// Loadouts: every time a member comes through the exit it picks one of its
// loadouts, favoring the ones that counter what the enemy team is fielding right
// now. Inside a Loadout block:
//   Name           shown in the console with "developer 1" when it's picked
//   Counters       what it's good against: class names, "Sentry" and "Giant",
//                  space separated - repeat a name to count it more
//   Orders         squad orders it suits: attack, defend, follow
//   Weight         how likely it is next to the others (default 1)
//   Item, ItemAttributes, CharacterAttributes, Attributes
//                  given on top of the member's own (an Item replaces whatever
//                  the member had in that slot)
// The *Kit templates below hold a loadout list per class - use them as a Template
// and add your own Loadout blocks on top.
//
// Squad size is capped by tf_robot_squad_max_per_team (shared by every Engineer on
// the team) and the server's free player slots, minus tf_robot_squad_reserve_slots.
// Big squads need a big server: e.g. -maxplayers 64.
//
// During Halloween / Full Moon the squads show up as undead instead of robots.
// Models are precached when the map loads, so a model added to these files later
// only shows up after a map change.
//
// Popfile templates can be pasted in: MvM-only fields like ClassIcon are skipped,
// and fields from server plugins are skipped with a warning in the console.
// Reload with tf_robot_squad_reload (cheat), or change maps.
